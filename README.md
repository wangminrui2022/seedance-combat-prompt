## 📖 项目简介

**Seedance 2.0 二次元打戏提示词生成智能体**（`seedance-combat-prompt`）是一个面向 AI 视频生成模型 Seedance 2.0 的「打戏分镜师+摄影师」复合型提示词生成系统。

它把传统武术指导、漫画分镜师、好莱坞摄影指导的三重身份压缩进同一条 15 秒视频里——从开局 1.5 秒的冲击点、节奏呼吸、运镜衔接、情绪拐点，到终结技的三幕结构，全部用结构化的提示词语言表达出来，可直接粘贴进 Seedance 2.0 生成 15 秒高燃打戏。

### 🎯 一句话定位
> 「开局 1.5 秒就要炸，15 秒内必有情绪拐点，每一击都有来由、有去处、有叙事。」

## ✨ 核心特性

### 双重专业身份
- **🗡️ 动作指导能力**：攻防逻辑设计、日式动漫动作语法（瞬间消失→0帧蓄力→空中多段连击→碰撞瞬间时间凝固→效果延迟显示）、节奏编排、角色动作签名设计。
- **🎥 运镜指导能力**：镜头切换逻辑（运动方向衔接/动作弧线衔接/景别阶梯衔接）、景别呼吸感（特写→近景→中景→全景）、观众心理引导。

### 📐 完播率公式（最高指导原则）
```
完播率 = 开局冲击(20%) × 节奏呼吸(30%) × 运镜丰富度(25%) × 情绪拐点(25%)
```

| 因素 | 权重 | 执行标准 |
|------|------|----------|
| 开局冲击 | 20% | 1.5秒内必须出现攻防接触，禁止全景铺垫 |
| 节奏呼吸 | 30% | 快慢交替，同节奏连续≤5秒 |
| 运镜丰富度 | 25% | 同运镜≤2秒，同景别≤3秒，重磅招式三段式 |
| 情绪拐点 | 25% | 至少1次让观众情绪翻转的瞬间 |

### 🛡️ 7 条核心铁律 + 29 条执行级结构铁律
- **铁律1·无铺垫法则**：前 1.5 秒内必须出现攻防接触；共创验证：0.5 秒内出现"冲突最激烈的点"——两种极端招式正面硬撞+微慢镜定格。
- **铁律7·近景对招法则**：15秒内必须有至少 2-3 秒上半身近景对招，纯远景大动作≠完整打戏。
- **铁律22·景别匹配法则**：小幅动作→近景放大密度；大幅动作→全景展示张力。
- **铁律30·镜头规格强制系统**：每次必写 5 要素（景别·视角·角度·运镜·跟随目标）。

### 🎬 镜头规格强制系统
```
[景别]·[拍摄视角+角度]·[运镜方式]·[跟随目标]
```

**四档景别**：全景 / 中景 / 近景 / 特写 —— 每种景别都有强制的视角约束（中景及以上禁止 90° 侧面正拍）。

**四原则指导镜头选择**：
1. 正常速度对招 → 中近景·侧面·带移动感
2. 蓄力大前摇 → 仰视+慢推
3. 快速攻防 → 斜角+方向移动
4. 特写 → 破绽/转折点的过渡标点

**15 种专业运镜方式**：跟拍跟镜、环绕运镜、急速推镜、急速拉镜、慢速推近、定格定镜、快速平摇、升降运镜、慢动作跟镜、冲镜、过肩运镜……

## 🎯 提示词输出结构

每条 15 秒提示词同时覆盖 **6 层结构**：

| 层级 | 内容 | 核心要求 |
|------|------|----------|
| 1 | 角色设定层 | 明确双方武学、定位、动作签名、特效性格 |
| 2 | 动作攻防层 | 每一击有来由、有去处、有攻防转换，拒绝为打而打 |
| 3 | 节奏结构层 | 开局冲击→近景对招→空间变化→情绪拐点→终结技 |
| 4 | 镜头运镜层 | 每段写完整景别/视角/角度/运镜/跟随目标 |
| 5 | 特效反馈层 | 劲气绑定身体部位和动作轨迹 |
| 6 | 场景渲染层 | 风格、空间、环境反馈链 |

### 镜头规格示例

```
# ✅ 正确示例
中景·45°斜拍平视·跟拍跟镜·跟随两人攻防交错横向平移

# ❌ 错误示例（中景及以上禁止 90° 侧面正拍，会变成"格斗游戏"既视感）
中景·侧面90°平视
```

### 近景对招示例（招式序列化机枪节奏）

```
✅ "右摆拳打脸→左勾拳打下巴→右直拳打鼻梁→左摆拳打太阳穴→右勾拳打下颌→左直拳打面门；
   防守方头部左偏、右偏、后仰、侧闪，全部躲开或格开。"

❌ "机枪节奏/快速连击"（禁止抽象参数）
❌ "每秒攻击≥3次"（禁止纯定性词）
```

## 📐 核心方法论

### 上半身近景对招体系

```
远景/全景  → 看"大动作"（腾空/旋转/下劈/撑地）→ 视觉奇观型观赏性
近景/中近景 → 看"杀意"（拳脚交错/格挡弹开/寸拳贴脸）→ 密度压迫型观赏性
```

**机枪节奏 vs 炮弹节奏**：
```
【炮弹节奏】= 远景大动作的节奏
  砰——————砰——————砰！
【机枪节奏】= 近景对招的节奏
  砰砰砰砰——砰！砰砰砰——砰！！
```

### 冷暖色彩对抗铁律

| 规则 | 说明 |
|------|------|
| **同色系特效打架永远不如互补色好看** | 紫(白鸽) vs 蓝(冰女) 都是冷色系，视觉上"打架打不起来" |
| **冷暖对比=视觉冲突最大化** | 加深紫到偏暖品红+保持冰女冷青蓝=暖紫刺入冷蓝 |
| **花瓣vs火焰用明暗区分** | 芭乐深粉 vs 红茶橙红，暖色对暖色时用亮度/饱和度拉开差距 |

## ❓ 常见问题

### Q1: 智能体和直接写提示词有什么区别？
**A:** 直接写提示词只能凭感觉；本智能体把"动作指导+摄影指导+节奏设计+特效设计+运镜衔接"五重专业身份压缩进结构化铁律，每一条提示词都遵循可量化的 7 条核心铁律 + 29 条执行级铁律。

### Q2: 必须用默认角色吗？
**A:** 不是。可以创建任意新角色，智能体会先展示「技法-招式」总览，按主战/破招/终结层级分配招式，再生成完整的角色卡。

### Q3: 风格和场景如何选择？
**A:** 智能体内置 5 个默认视觉风格（真人武侠/真人格斗/3D国漫/二次元/赛博朋克）和 20 个默认打斗场景。当你没想好时，智能体会主动引导你选择；想自定义风格和场景也可以直接描述。

### Q4: 镜头规格必须按 `[景别]·[视角]·[角度]·[运镜]·[跟随目标]` 五要素写吗？
**A:** 是的。这是铁律 30，每次命中场景都必须写完整五要素，才能保证运镜丰富度评分。
